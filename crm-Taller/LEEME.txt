2. CÓMO ARRANCAR EL PROYECTO
--------------------------------------------------------------------------------
- En Windows: ejecutar el archivo `iniciar.bat` (doble clic o desde la terminal).
- En Linux / macOS: ejecutar `bash iniciar.sh`.

El script se encarga de crear el entorno virtual, instalar dependencias,
aplicar migraciones, cargar los datos de ejemplo y levantar el servidor.
